How these were solved. Both engines chase the same targets: the contrast curve measured off Radix Colors (blue for accents, slate for the neutral). Leonardo interpolates the seed through OKLCH and picks the color that lands on each ratio. HCT keeps the seed's hue and chroma fixed and solves only tone (tone = L*, so contrast is a function of tone distance). Where they disagree, it is in how much color each step keeps, not in how much contrast it has.
